🎯 나의 학습 목표

단순히 코드를 외우는 것을 넘어, 변수의 원리를 이해하고 값을 바꿔가며 결과를 예측할 수 있는 사람이 되는 것입니다.

📌 나의 학습 사례 (STAR)

S

Situation (상황)

파이썬 Chapter 1에서 변수(Variable)에 숫자를 담고, 그 변수를 사용해 계산하는 방법을 배우고 있었습니다.

T

Task (과제/목표)

변수 x에 들어있는 값을 바꾸면, 같은 계산식(x + 2)의 결과도 따라서 바뀌는지 직접 확인해 보고 싶었습니다.

A

Action (행동)

(내가 한 일) 직접 코드를 작성해서 x에 숫자 3을 넣고 print(x + 2)를 실행해 봤습니다. 그다음 x의 값을 8로 수정하고 파일을 다시 실행했습니다.

(AI가 도운 일) 코드를 짜다가 에러가 났을 때, AI에게 "변수에 값을 넣는 방법과 출력하는 방법의 차이"를 물어보고 설명을 들었습니다.

R

Result (결과)

처음에는 출력 결과로 5가 나왔고, x를 8로 바꾼 뒤에는 10이 출력되었습니다. "변수에 들어있는 값을 바꾸면, 그 변수를 쓰는 계산식의 결과도 바뀐다"는 원리를 확실하게 이해하게 되었습니다.
